Achievement Report Generator
============================

Version: 0.1.0

What it does
------------
Adds a shortcode for an Arabic RTL achievement-report form with a live A4 report preview and a print button. Data stays in the browser and is not saved in WordPress.

Install
-------
1. In WordPress, go to Plugins > Add New Plugin > Upload Plugin.
2. Upload achievement-report-generator.zip and activate it.
3. Create a new page (or edit a page in Elementor).
4. Add this shortcode using a Shortcode block/widget:
   [achievement_report_generator]
5. Preview the page and test Print.

Print settings
--------------
Use A4, Portrait, scale 100%, and disable browser headers/footers. If colors do not print, enable Background graphics in Chrome's print dialog.

Important
---------
The Arabic labels and sample values in version 0.1.0 were entered by reading the supplied reference image and may need correction. Review them before using the report officially. This initial version does not save reports and does not include a logo upload or user permissions.
